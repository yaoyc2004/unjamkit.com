CSV to Excel questions, answered.

Can’t I open a CSV in Excel and save it as an XLSX?

Yes, if Excel imports the identifier columns as Text first. If Excel already turned 00123 into 123 when opening the CSV, Save As stores 123; it cannot recover the lost zero. This tool reads the original CSV as text and creates an XLSX with explicit text cells before Excel opens it.

Why does Excel remove leading zeros from CSV files?

CSV files do not carry spreadsheet cell types. When a spreadsheet interprets a field as a number, it may remove leading zeros or change long identifiers. This tool writes an XLSX with explicit text cells so the field text is preserved on opening.

Can I calculate with the prices and quantities?

All values are text in this version. Convert only the columns you need for arithmetic in Excel, after checking their decimal and thousands separators. Keep identifier columns as text.

What exactly does the check verify?

The generated workbook is read back in your browser. Every cell in the Data sheet is checked for the same text, text cell type and position as the parsed CSV; formula cells are not permitted. This checks the conversion, not whether the source data was already damaged.

What happens to blank lines, spaces and repeated headers?

Spaces, repeated header names, record order and line breaks inside quoted fields are preserved. Blank records stay as blank rows; one final line ending is treated as the end of the last record. The header setting changes the preview and counts, not the content of the Data sheet. No header is invented when the setting is off.

Which files are supported?

One UTF-8 CSV, with or without a UTF-8 BOM, up to 10 MB. Comma, semicolon, tab and pipe separators are supported. Limits are 50,000 data records plus an optional header, 256 columns, 250,000 total cells and 32,767 characters per cell. Files with invalid quoting, inconsistent field counts, unsupported control characters, ambiguous Excel escape-shaped text or a different encoding are rejected instead of silently changed.

Will identifiers stay intact if I save it as CSV again?

The downloaded XLSX stores text cell types. A CSV does not. Opening a later CSV export or converting these cells to numbers can change the values again. Hand over the XLSX and keep identifiers as text.
