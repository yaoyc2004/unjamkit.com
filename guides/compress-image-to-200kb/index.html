How to compress a photo to 200 KB.
Or 100 KB, or any form limit.

File size depends on two things: pixel dimensions and JPEG quality. A phone photo is usually 3,000–4,000 pixels wide and several megabytes. To get under 200 KB, first shrink it to the size the form actually needs (1,200–1,600 pixels wide is plenty for most forms), then lower JPEG quality until it fits. Image Fit does both automatically: enter 200 and download a JPG under the limit.

What “200 KB” means

Most forms mean 200 × 1,024 = 204,800 bytes, but some count 1 KB as 1,000 bytes. If an upload just over the limit is rejected, aim a little lower, such as 195 KB. The limit is a maximum: a 150 KB file is fine.

Also check the form’s other rules. A size limit often comes with a required format (usually JPG), minimum or exact pixel dimensions, an aspect ratio or a background colour. Compressing does not crop a photo or check passport-photo rules.

The quick way: Image Fit

  1. Open Image Fit and choose the JPG, PNG or WebP photo.
  2. Enter the limit in KB, for example 200 or 100. Add a maximum width if the form asks for one.
  3. Click Make it fit, check the preview and the reported size, and download the JPG.

The tool searches JPEG quality and, if allowed, reduces dimensions until the file fits. The photo is processed in your browser and not uploaded. iPhone HEIC photos need converting first with HEIC Convert.

Doing it by hand

Windows (Paint)

Open the photo in Paint, choose Resize, select Pixels and set the width (keep the aspect ratio), then File → Save as → JPEG picture. Paint has no quality setting, so if the file is still too large, resize again to a smaller width.

Mac (Preview)

Open the photo in Preview, choose Tools → Adjust Size and set the width. Then File → Export, choose JPEG and move the Quality slider: Preview shows the resulting file size before you save.

Tips for a clean result

  • Crop first. Removing empty background saves more bytes than lowering quality, and keeps the subject sharp.
  • Screenshots with text blur quickly under heavy JPEG compression; reduce dimensions rather than quality, and check that the text is still readable.
  • PNG files with transparency become JPG with a white background. A form that requires PNG needs a different tool.
  • Keep the original. Compression is lossy and can’t be undone.
