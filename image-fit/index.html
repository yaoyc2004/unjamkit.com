The details, in plain language.

Enter the maximum allowed size. “200 KB” means the downloaded JPEG will be at most 200 × 1,024 bytes; it need not be exactly that size. If a form uses decimal KB, choose a slightly lower limit.

The tool adjusts JPEG quality and, if you allow it, image dimensions. A width setting is a maximum, not an instruction to enlarge the original. Tiny targets cannot preserve every detail.

JPEG output does not preserve the source’s transparency, animation or original metadata. This version handles one image at a time; HEIC and batch conversion are outside this first version.
